# 演示指南（答辩用）

> 环境：本地 `pnpm dev`（http://localhost:3100）或华为云部署地址。
> 前置：`.env` 中已配置真实 `DEEPSEEK_API_KEY`，网络可访问模型端点。

## 0. 演示模式（/demo）与视频录制

- 打开 `http://localhost:3100/demo`：自动完成「提问 → 五阶段推演 → 分阶段揭示结果 → 保存账本」，
  页面底部常驻**解说字幕**（01/12 → 12/12），适合投屏讲解或直接录屏。
- 演示内容为真实 DeepSeek 调用（约 30-60 秒），不是预录数据；失败会明确报错，不伪造。
- 本作品的演示视频即用 Playwright 无头录制该页面 + 账本详情（含现场复盘）+ 复盘统计 + 模型库，
  再用 ffmpeg 转码为 H.264 MP4（1440×810，约 2 分 14 秒）。录制脚本位于工作区 `video-tools/`。

## 1. 预设演示问题（已实测，效果稳定）

| 问题 | 预期出现的张力对 | 看点 |
| --- | --- | --- |
| 一个已经投入 18 个月的产品，留存不温不火，到底该不该继续？ | 沉没成本 × 路径依赖 | 差评原题；缺失信息会点名"留存口径、CAC/LTV、行业基准" |
| 两份 offer 都不错：一份钱多但成长慢，一份钱少但成长快，怎么选？ | 锚定/机会成本类张力 | 展示"比较选择"类模型与贝叶斯证据检查点 |
| 我想从零开始做一个 AI 学习类产品，值得做吗？ | 幸存者偏差 × 基本比率 | 展示"检查偏差"角色模型与最小可行实验 |

## 2. 三分钟演示脚本（核心）

1. **提问（20s）**：粘贴预设问题 1，点"开始推演"；推演中页面实时显示五阶段进度与每阶段耗时——强调"固定五阶段、无循环"。
2. **模型对阵（30s）**：指出 ⚔️ 张力标记（沉没成本 × 路径依赖），念一条冲突的"各自在什么条件下成立"。
3. **溯源回放（30s）**：展开面板——"这就是拒绝黑盒：为什么选这个模型、喂了什么上下文、模型原始输出是什么，全部留档"。
4. **五层标注（20s）**：结论区图例；指出数字都标着"仅为示例，不是推荐阈值"——直接回应差评第 3 条。
5. **账本闭环（40s）**：保存到认知账本 → 现场追问（系统自动携带上一轮回答）→ 账本详情 → 填复盘表单 → 打开复盘统计页看长期认知轨迹。

## 3. 十分钟加长版补充

- 工作台里的「简明 / 完整推演」切换：默认只给结论与关键冲突，需要时再展开每个模型的论证、关系图与溯源回放；
- 模型库（42 个）：按「看问题的方式」或「领域」筛选；卡片先给一句大白话，点「展开详解」才看定义、适用范围、失效边界与来源；
- 账本详情底部的「旁参」：黄历 / 星象 / 六爻一页，默认折叠，仅作换视角参照，不参与判断（讲解时说明它的小单元定位）；
- 首页理念 + 完整路径图；
- 代码层：`lib/pipeline.ts` 五阶段流水线、`lib/store.ts` 存储适配器（华为云 RDS/Redis 预留）、`lib/models-data.ts` 可溯源模型库、`lib/plain-explain.ts` 大白话与领域分类。

## 4. 常见评委问题预案

**Q：模型检索是怎么做的？为什么可信？**
A：确定性关键词/标签匹配（命中结果可解释、可复现），再由模型从候选中选择并给出选择理由；
张力对由库内显式声明的 tensionWith 关系兜底保证——不满足就用确定性规则补入，不依赖模型自觉。

**Q：怎么保证模型不编数字？**
A：三层约束：提示词铁律（数字只能来自用户事实，否则必须标"示例"）+ 输出 JSON 契约校验（layer 枚举）+
UI 强制五层标注展示。实测输出中所有无依据数字都带"仅为示例，不是推荐阈值"。

**Q：多模型推演会不会死循环/超时？**
A：架构上不可能死循环——固定五阶段顺序执行，每阶段最多两次模型调用（一次正常 + 一次 JSON 修复），
单次调用 60 秒超时；任何失败明确报错，不伪造。

**Q：和观猹上那个"认知脚手架"有什么区别？**
A：本作品把差评指出的三件事做成硬功能：强制模型张力（不是共同论证）、五层标注（数字示例化）、
认知账本（存判断过程 + 复盘 + 长期轨迹），并且每一步都可溯源回放。

**Q：赛题要求华为云码道 + RDS/Redis，体现在哪？**
A：标准 Node/pnpm 工程可直接在码道 CodeArts 流水线构建；存储层是抽象接口（LedgerStore），
本地 JSON ↔ 华为云 RDS 切换零业务改动；Redis 用于会话/限流，未配置自动降级。详见
docs/华为云码道-赛题一适配.md。

**Q：数据存在哪？隐私如何？**
A：账本默认本地文件（单机可跑）；上线切 RDS。除推理所必需的问题与上下文发送给模型 API 外，
不上传任何数据；Key 走环境变量，绝不入库。

## 5. 故障预案

- 模型 API 异常：页面会如实报错并给出原因与重试按钮（这本身就是"拒绝伪造"的演示点）；
- 无网络/无 Key：诚实说明该作品定位是真实推理，不做离线假输出；可先演示模型库与账本/统计页（本地数据功能不受影响）。
