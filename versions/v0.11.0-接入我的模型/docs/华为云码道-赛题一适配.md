## 2. 存储适配层（关联华为云 RDS / Redis）

**已实现，不只是预留**：

- `lib/store.ts`：`LedgerStore` 抽象接口 + `getStore()` 按环境变量选择实现；
- `lib/store-postgres.ts`：`PostgresLedgerStore`（真实 SQL：`ledger` 表 + `data jsonb`），
  表结构在启动时自动创建（`CREATE TABLE IF NOT EXISTS`），首次请求时建立连接池（max=10）；
- `lib/rate-limit.ts`：`RedisLimiter`（INCR + EXPIRE 按小时窗口计数）+ 内存降级；
  `/api/analyze` 已接入限流（`RATE_LIMIT_PER_HOUR`，默认 30 次/IP/小时）；
- 本地验证：`tests/store.test.mjs` 用 `pg-mem`、`ioredis-mock` 跑同一套 SQL 与限流逻辑（CI 必跑）；
- `docker-compose.yml` 已带 `postgres:16` + `redis:7`（含健康检查），
  打开 `LEDGER_STORE=postgres` 即可切到数据库存储。

切换方式（业务代码零改动）：

```bash
LEDGER_STORE=postgres
RDS_CONNECTION_STRING=postgres://user:pass@rds-host:5432/cognitive_scaffold
REDIS_URL=redis://redis-host:6379
```

华为云侧：RDS 创建 PostgreSQL 实例后，把连接串写入环境变量即可；
Redis（DCS）同理。两者都通过码道的 Skills / 云服务开通后获取连接信息。

## 3. 华为云部署步骤（ECS / CCE）

```bash
# 方式一：ECS 上用 Docker 部署
docker build -t cognitive-scaffold .
docker run -d --name cognitive-scaffold -p 3000:3000 \
  -e DEEPSEEK_API_KEY=sk-xxxx \
  -e DEEPSEEK_BASE_URL=https://api.deepseek.com \
  -e DEEPSEEK_MODEL=deepseek-chat \
  -v cognitive-scaffold-data:/app/data \
  cognitive-scaffold
```

```bash
# 方式二：CCE 部署（docker-compose 同构）
# 推送镜像到华为云 SWR 后，创建无状态负载，注入上述环境变量，
# 并挂载持久卷到 /app/data（使用 RDS 后无需该卷）。
```

CodeArts 流水线配置要点：Node.js 构建模板 → `pnpm install && pnpm build` →
镜像构建（Dockerfile）→ 推送 SWR → 部署到 ECS/CCE。应用端口 3000。

## 4. 环境变量清单

| 变量 | 必填 | 说明 |
| --- | --- | --- |
| `DEEPSEEK_API_KEY` | 是 | DeepSeek API Key（或华为云 ModelArts 推理端点对应的 Key） |
| `DEEPSEEK_BASE_URL` | 否 | OpenAI 兼容端点，默认 `https://api.deepseek.com`；接华为 ModelArts 时替换 |
| `DEEPSEEK_MODEL` | 否 | 模型名，默认 `deepseek-chat` |
| `LEDGER_STORE` | 否 | `file`（默认）/ `postgres` |
| `RDS_CONNECTION_STRING` | 否 | LEDGER_STORE=postgres 时必填（RDS PostgreSQL 连接串） |
| `REDIS_URL` | 否 | 限流计数（DCS Redis），未配置自动降级到内存 |
| `RATE_LIMIT_PER_HOUR` | 否 | 每 IP 每小时推演次数上限，默认 30 |

## 5. 现场演示建议（3 分钟版）

1. 工作台提问（用差评同款问题："一个已经投入 18 个月的产品到底该不该继续？"）——展示五阶段推演实时进度；
2. 重点展示：模型对阵里的 **⚔️ 张力对**（沉没成本 × 路径依赖）→ 冲突点与各自成立条件 → 证据检查点；
3. 展开 **溯源回放**："AI 是怎么一步步得出这个答案的"，每步输入/输出全留档——拒绝黑盒；
4. 结论区 **五层标注**：数字全部标注"仅为示例，不是推荐阈值"；
5. 保存到认知账本 → 演示追问（自动携带上一轮回答）→ 账本详情 → 复盘表单回填；
6. 复盘统计页：长期认知轨迹与常犯偏差信号。
