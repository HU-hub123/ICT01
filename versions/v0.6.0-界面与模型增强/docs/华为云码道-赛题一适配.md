## 2. 存储适配层（关联华为云 RDS / Redis）

代码位置：`lib/store.ts` —— 已定义 `LedgerStore` 抽象接口（list / get / save / addReview），
当前实现为本地 JSON 文件存储（`FileLedgerStore`，零依赖、单机可跑）。

接入华为云服务时的切换方式（业务代码零改动）：

1. **RDS（PostgreSQL/MySQL）**：新增 `RdsLedgerStore` 实现同一接口，使用 SQL 持久化认知账本；
   通过环境变量 `LEDGER_STORE=rds` + `RDS_CONNECTION_STRING` 切换。
2. **Redis**：用于会话缓存与推演请求限流（防并发打爆模型额度），
   环境变量 `REDIS_URL` 配置，未配置时自动降级为内存实现。
3. 在码道中，这两类服务的"快速开通创建"可直接通过华为云 Skills / CLI 完成，
   开通后只需把连接串写入环境变量（部署配置），应用即自动切换。

## 3. 华为云部署步骤（ECS / CCE）

```bash
# 方式一：ECS 上用 Docker 部署
docker build -t cognitive-scaffold .
docker run -d --name cognitive-scaffold -p 3000:3000 \
  -e DEEPSEEK_API_KEY=sk-xxxx \
  -e DEEPSEEK_BASE_URL=https://api.deepseek.com \
  -e DEEPSEEK_MODEL=deepseek-chat \
  -v cognitive-scaffold-data:/app/data \
  cognitive-scaffold
```

```bash
# 方式二：CCE 部署（docker-compose 同构）
# 推送镜像到华为云 SWR 后，创建无状态负载，注入上述环境变量，
# 并挂载持久卷到 /app/data（使用 RDS 后无需该卷）。
```

CodeArts 流水线配置要点：Node.js 构建模板 → `pnpm install && pnpm build` →
镜像构建（Dockerfile）→ 推送 SWR → 部署到 ECS/CCE。应用端口 3000。

## 4. 环境变量清单

| 变量 | 必填 | 说明 |
| --- | --- | --- |
| `DEEPSEEK_API_KEY` | 是 | DeepSeek API Key（或华为云 ModelArts 推理端点对应的 Key） |
| `DEEPSEEK_BASE_URL` | 否 | OpenAI 兼容端点，默认 `https://api.deepseek.com`；接华为 ModelArts 时替换 |
| `DEEPSEEK_MODEL` | 否 | 模型名，默认 `deepseek-chat` |
| `LEDGER_STORE` | 否 | `file`（默认）/ `rds` |
| `RDS_CONNECTION_STRING` | 否 | LEDGER_STORE=rds 时必填 |
| `REDIS_URL` | 否 | 会话缓存/限流，未配置自动降级 |

## 5. 现场演示建议（3 分钟版）

1. 工作台提问（用差评同款问题："一个已经投入 18 个月的产品到底该不该继续？"）——展示五阶段推演实时进度；
2. 重点展示：模型对阵里的 **⚔️ 张力对**（沉没成本 × 路径依赖）→ 冲突点与各自成立条件 → 证据检查点；
3. 展开 **溯源回放**："AI 是怎么一步步得出这个答案的"，每步输入/输出全留档——拒绝黑盒；
4. 结论区 **五层标注**：数字全部标注"仅为示例，不是推荐阈值"；
5. 保存到认知账本 → 演示追问（自动携带上一轮回答）→ 账本详情 → 复盘表单回填；
6. 复盘统计页：长期认知轨迹与常犯偏差信号。
