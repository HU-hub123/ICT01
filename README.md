# 认知工作台（暂定名，待对齐）

> 把犹豫不决的问题，变成一场有对手的推演。
> 多模型交叉验证 · 五层标注 · 认知账本 —— 面向第十一届华为 ICT 大赛创新赛「赛题一」。

## 这是什么

基于"多模型交叉验证"的认知脚手架类网页应用：用户提出一个需要判断的问题，
系统检索多个思维模型并强制产生**张力推演**，把 事实 / 推断 / 假设 / 缺失信息 / 示例数字
**分层标注**，给出最小行动与停止条件，并把"判断过程"（而非聊天记录）存入**认知账本**，支持复盘与长期轨迹。
