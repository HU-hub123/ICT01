# 认知脚手架 · 可溯源思考工作台

> 让 AI 的思考过程被看见、被检查、被记住、被复盘 —— 拒绝黑盒。
> 认知脚手架 · 多模型交叉验证 · 五层标注 · 溯源回放 · 认知账本 —— 面向第十一届华为 ICT 大赛创新赛「赛题一」。

## 这是什么

这是"认知脚手架"类网页应用：用户提出一个需要判断的问题，AI 通过多个思维模型的**张力交叉推演**得出结论；但结论只是副产品，真正交付的是**可溯源的思考过程**——为什么选这些模型、每个模型怎么推、模型之间在哪里冲突、什么新证据会改变结论，每句话标注 事实 / 推断 / 假设 / 缺失信息 / 示例数字 的成色，最后给出最小行动与停止条件，并把整条判断过程（而非聊天记录）存入**认知账本**，支持溯源回放与复盘。核心目标：**帮助人看懂、记住、回顾 AI 是怎么得出答案的，拒绝黑盒。**

## 项目结构

```
app/                 页面与 API（App Router）
  api/analyze        五阶段推演接口（SSE 流式返回）
  api/ledger         认知账本保存/列表/详情/复盘
  api/models         可溯源模型库
  ask/               工作台（提问→推演→五层标注→溯源回放→追问）
  models/            模型库浏览（按认知操作角色筛选）
  ledger/            认知账本列表/详情/复盘统计
components/          工作台、模型卡片、张力面板、溯源回放、复盘表单等
lib/
  models-data.ts     30 个可溯源思维模型（角色/动作/边界/谱系/信源/张力对）
  retrieval.ts       确定性检索（关键词/标签 + 张力对兜底）
  prompts.ts         五阶段提示词（JSON 契约 + 反幻觉铁律）
  pipeline.ts        固定五阶段流水线（防死循环：无迭代、有收敛）
  deepseek.ts        DeepSeek Provider（真实调用，超时/重试/明确报错）
  store.ts           存储适配器（本地 JSON ↔ 预留华为云 RDS/Redis）
  stats.ts           复盘统计（长期认知轨迹、常犯偏差信号）
docs/                产品设计、演示指南、华为云码道适配说明
versions/            按版本归档的完整快照（v0.1.0 → v0.4.0）
```

## 技术方案（已实现）

Next.js 15 全栈（TypeScript + Tailwind）· DeepSeek 真实推理（OpenAI 兼容，可换华为 ModelArts）· 存储适配层（本地 JSON 文件 ↔ 预留华为云 RDS/Redis）· 30 个可溯源思维模型

## 本地运行

```bash
# 1. 复制 .env.example 为 .env，填入真实 DEEPSEEK_API_KEY
# 2. 安装依赖并启动
pnpm install
pnpm dev          # 打开 http://localhost:3100
```

> 推理层为固定五阶段顺序执行（每阶段最多两次模型调用），不存在循环推理；任何一步失败都会明确报错，绝不伪造输出。

### Docker 一键部署（华为云 ECS/CCE 同构）

```bash
docker compose up --build   # 打开 http://localhost:3000
```

生产构建验证：`pnpm build`；CI 见 [.github/workflows/ci.yml](.github/workflows/ci.yml)。
